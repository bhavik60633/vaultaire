- [x] R3 StrongBox availability and latency; TEE-only policy: StrongBox on the S20 Ultra, TEE only on the A12; **TEE-only phones supported**, StrongBox used when present. Per-use latency moves to G2 with the other real-phone key tests
- [x] R4 key invalidation on lock-screen removal; OEM variance after OS updates: **accepted for G0, moved to G2** (needs a spare phone; never an owner's daily phone)
- [x] R5 Argon2id: 798 ms on the A12; cracking cost of the 10¹² policy ≥ about $69,000 per vault even for a pessimistic attacker who already holds the Recovery Secret ([research](../research/g0-desk-research.md#r5-remaining-part-what-does-offline-guessing-cost-an-attacker))

- [x] R7 assistants and `FLAG_SECURE`: screen capture (Circle to Search, Gemini overlay) is blocked; autofill is not (T31) ([research](../research/g0-desk-research.md#r7-do-assistants-and-on-screen-ai-read-flag_secure-windows)). Device check at G3
- R8–R11 are iOS items, deferred to Gate G7.
