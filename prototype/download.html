How to install on Samsung Galaxy:

  1. Tap Download Release APK above.
  2. If Samsung Internet / Chrome shows "File might be harmful", tap Download anyway.
  3. When download finishes, tap Open (or open My Files → Downloads).
  4. If prompted "Install unknown apps", tap Settings and switch on Allow from this source for your browser / My Files.
  5. Tap Install and then open Vaultaire Spike.
